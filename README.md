# 醫道（1828 序，京都大學 イ/243） / Idō [The way of medicine]: Transcription Dataset

中川壺山《醫道》以十一章論醫者如何診察、讀書、理解治法，以及醫者的責任。京都大學富士川文庫刊本有文政十一年（1828）序、作者文政丙戌（1826）自跋，部分版面保留日文漢文訓讀標記。

Nakagawa Kozan's Idō discusses observation, reading, therapeutic reasoning, and a physician's responsibilities in eleven chapters. The Fujikawa Collection print held by Kyoto University contains a preface dated 1828, the author's afterword dated 1826, and Japanese reading annotations.

## V0.1.0

這版提供 33 幅影像的逐幅定位。本版記錄 AI 輔助初讀；別頁、夾注及可辨原筆標記依位置編碼。

This edition covers 33 scans. This edition preserves an AI-assisted initial reading, with visible notes and other features referenced to the scan.

利用 AI 輔助逐頁轉錄並保留原字、版面與疑讀。人類全文雙校、專家審定、同儕審查及準確率量測尚未進行。實際模型識別與使用量未知。此資料公開供比對與引用，處理程式及影像另存。

The dataset uses AI-assisted transcription and preserves source forms, layout and uncertain readings. Human proofreading, expert review, peer review and accuracy measurement are pending. The actual model identifiers and usage are unknown.
